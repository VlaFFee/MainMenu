# CyberMenu (Minecraft 1.20.1, Forge 47.2.0+)

Клиентский мод: кибер-тема для всех меню. На сервер ставить не нужно.

## Что меняет
- **Главное меню** — терминал: логотип OUTSIDE «расшифровывается» из случайных символов, периодический глитч, пункты выезжают
  по очереди, подсветка и звук при наведении, управление мышью и стрелками/Enter, лог загрузки внизу.
- **Живой фон** на всех меню и настройках: бесконечный туннель из светящихся синих точек (спираль, штрихи к краям,
  волны яркости, мерцание, редкие зелёные искры), центр плавно следует за мышью. Фон не перезапускается при смене экрана.
- **Меню поверх мира** (пауза, настройки в игре): мир затемняется синим, поверх идут точки и развёртка.
- **Кнопки и ползунки** во всех меню получают кибер-скин: свечение, бегущая заливка, угловые скобки, вспышка при клике.
  Работает и в списках настроек (графика, звук, управление). Ввод остаётся у оригинальных кнопок, ничего не ломается.
- **Появление кнопок**: каждый экран открывается с каскадом, кнопки въезжают по очереди.
- **Переходы между экранами** в компьютерном стиле, один из трёх случайно: развёртка линией с шумом, «расшифровка» блоками с мелькающими
  hex-цифрами, полосы данных, уезжающие в стороны. Каждый переход сопровождается коротким цифровым звуком.
- **Звуки интерфейса**: тихие компьютерные «тик» при наведении и «бип» при клике. Ванильный звук клика кнопок заменён на компьютерный
  во всей игре (ресурс `minecraft:ui.button.click`). Громкость: `soundVolume`.
- **Цифры на фоне**: дождь из шестнадцатеричных символов и всплывающие числа (hex, двоичные, десятичные), которые мелькают.
- **Компьютерный гул** в меню без мира: плавно нарастает при входе и затихает при выходе. Громкость: `humVolume`.
- Фон списков (бывшая «земля») заменён тёмно-синей плиткой.

Инвентари, чат, книги и таблички не трогаются.

- **Выход из игры**: интерфейс гаснет, по центру печатается «Я ещё увижу твой код», затем экран схлопывается как монитор в линию и точку, после этого игра закрывается.

## Настройки
Файл `config/cybermenu-client.toml` (появляется после первого запуска):
`replaceTitle`, `themeScreens`, `skinWidgets`, `transitions`, `inWorld`, `moddedScreens`,
`density` (плотность точек, меньше = выше FPS), `speed` (скорость фона),
`humVolume` (громкость гула, 0 = выключить), `soundVolume` (громкость звуков интерфейса), `digits` (цифры на фоне).

## Совместимость
Моды пакетной отрисовки (ImmediatelyFast, Embeddium) выводят текст поверх всех заливок. Поэтому мод на время кадра прячет
ванильную подпись кнопки и рисует свою, а перед своими слоями сбрасывает накопленную отрисовку.
Экраны Embeddium/Sodium и их дополнений не трогаются. Если в оформлении случится ошибка, мод отключает себя до перезапуска
и пишет в `latest.log` строку `[CyberMenu]` со стеком, игра при этом не падает.

## Сборка
Как в предыдущем моде: загрузить проект на GitHub, Actions → Build mod → Artifacts → `cybermenu-jar`.
Jar положить в `mods`.
